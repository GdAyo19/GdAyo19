## A little about me

Hey, I'm **Ayodeji**, but most people here know me as **GdAyo**.

I like taking an idea and figuring out how to make it work in real life. A lot of my learning happens by building: writing the API, connecting the database, testing the rough edges, and going back to fix what I missed.

I work mostly with **Go and Python**, and I'm growing into TypeScript and full-stack product work too. I'm especially interested in backend systems, APIs, data, and tools that make everyday tasks easier.

## What I'm building now

### 🎙️ [VoiceOrder](https://github.com/GdAyo19/voice_order)

An experiment in ordering food by speaking instead of typing. I'm building a small FastAPI service that accepts an audio file and returns a transcript, and testing speech recognition with Vosk and Whisper against a sample restaurant menu.

This is still a prototype. I'm working out how to make the transcription useful for an actual order—not just turn audio into text.

### 💛 [Tandem](https://github.com/GdAyo19/duo-together)

A little language-learning space for couples to practice together, play short quizzes, and save phrases they want to remember.

The MVP is live on [GitHub Pages](https://gdayo19.github.io/duo-together/). I'm improving the foundations too: adding tests and CI, organizing the app, and preparing versioned Supabase migrations and shared progress features. Cloud sync still needs a Supabase project to be configured, so for now progress is saved in the current browser.
